# MCP Server + MCP-UI Coffee Place Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a standalone MCP server to this repo that the Rails app calls as an MCP client, where one tool returns an MCP-UI HTML resource ("card") for a coffee place that Rails renders in a sandboxed iframe.

**Architecture:** `mcp_server/` is a plain Ruby process (booted via `bin/mcp_server`) that loads the Rails app's `config/environment.rb` to reuse `CoffeePlace`/`Beverage` models, then serves two MCP tools over the Streamable HTTP transport (`mcp` gem) on port 3001. The Rails app (port 3000) is the MCP client: `Mcp::Client` (our own wrapper, `app/services/mcp/client.rb`) calls the `get_coffee_place_card` tool and the coffee place's `show` page embeds the returned HTML via a sandboxed `<iframe srcdoc="...">`.

**Tech Stack:** Ruby 3.4.1, Rails 8.1.3, `mcp` gem 1.2 (official Ruby MCP SDK, client + server), `mcp_ui_server` gem 0.1 (`McpUiServer.create_ui_resource`), rspec-rails, SQLite.

## Global Constraints

- Ruby `3.4.1` (`.ruby-version`), Rails `~> 8.1.3` — match the existing Gemfile.
- Gem versions: `mcp` `~> 1.2`, `mcp_ui_server` `~> 0.1`.
- MCP tools are **read-only** — no write/create tools on the MCP server (out of scope per spec).
- No postMessage/JSON-RPC handling for iframe-to-host messages — rendering is one-directional (out of scope per spec).
- Iframe embedding always uses `sandbox="allow-scripts"` with **no** `allow-same-origin` (MCP-UI security model — opaque origin, no access to the parent document or cookies).
- Match existing spec conventions: plain `ModelName.create!`/`.new` (no FactoryBot — none is used in this codebase), `type: "request"` for request specs, `require "rails_helper"` at the top of every spec.
- Match existing view conventions: semantic HTML (`<article>`, `<header>`), Pico CSS classless framework already loaded — no new CSS classes needed beyond what's already used (`notice`, `place-rating`, `place-favorite-drink`).
- The `Mcp` (mixed-case) Ruby namespace is **our own** app code (`app/services/mcp/client.rb` → Zeitwerk autoloads it as `Mcp::Client`); the `MCP` (all-caps) namespace belongs to the `mcp` gem (`MCP::Client`, `MCP::Tool`, `MCP::Server`, ...). They are different constants — keep the casing exactly as written in every task below.

# frozen_string_literal: true

class ListCoffeePlacesTool < MCP::Tool
  tool_name "list_coffee_places"
  title "List Coffee Places"
  description "Lists all coffee places with their address and rating"
  input_schema(properties: {}, required: [])

  class << self
    def call
      places = CoffeePlace.order(:id)

      text = places.none? ? "No coffee places yet." : places.map { |place| summarize(place) }.join("\n")

      MCP::Tool::Response.new([{ type: "text", text: text }])
    end

    private

    def summarize(place)
      rating = place.rating ? " (rating: #{place.rating}/5)" : ""
      "#{place.id}: #{place.name} — #{place.address}#{rating}"
    end
  end
end
```

# frozen_string_literal: true

class CoffeePlaceCardTool < MCP::Tool
  tool_name "get_coffee_place_card"
  title "Get Coffee Place Card"
  description "Returns an MCP-UI HTML card for a single coffee place"
  input_schema(
    properties: { id: { type: "integer", description: "The coffee place's id" } },
    required: ["id"],
  )

  class << self
    def call(id:)
      place = CoffeePlace.find_by(id: id)

      return not_found_response(id) unless place

      ui_resource = McpUiServer.create_ui_resource(
        uri: "ui://coffee-place-card/#{place.id}",
        content: { type: :raw_html, htmlString: card_html(place) },
        encoding: :text,
      )

      MCP::Tool::Response.new([ui_resource])
    end

    private

    def not_found_response(id)
      MCP::Tool::Response.new([{ type: "text", text: "No coffee place found with id #{id}" }], error: true)
    end

    def card_html(place)
      rating_html = place.rating ? ("★" * place.rating) + ("☆" * (5 - place.rating)) : "Not rated"
      drink_html = place.favorite_drink ? "<p>Favorite drink: #{ERB::Util.html_escape(place.favorite_drink.name)}</p>" : ""

      <<~HTML
        <!doctype html>
        <html>
          <head><meta charset="utf-8"></head>
          <body style="font-family: sans-serif; margin: 0; padding: 1rem;">
            <h2>#{ERB::Util.html_escape(place.name)}</h2>
            <p>#{ERB::Util.html_escape(place.address)}</p>
            <p>#{rating_html}</p>
            #{drink_html}
          </body>
        </html>
      HTML
    end
  end
end
```

- [ ] **Step 3: Write `app/services/mcp/client.rb`**

```ruby
# frozen_string_literal: true

require "net/http"
require "base64"

module Mcp
  class Client
    class ConnectionError < StandardError; end
    class ToolError < StandardError; end

    def initialize(server_url: ENV.fetch("MCP_SERVER_URL", "http://localhost:3001"), mcp_client: nil)
      @server_url = server_url
      @injected_client = mcp_client
    end

    def coffee_place_card(id)
      client = mcp_client

      begin
        client.connect(client_info: { name: "coffee_spots", version: "1.0" })
        result = client.call_tool(name: "get_coffee_place_card", arguments: { id: id })

        raise ToolError, error_text(result) if result["isError"]

        html(result)
      rescue Errno::ECONNREFUSED, SocketError, Net::OpenTimeout, Net::ReadTimeout => e
        raise ConnectionError, "Could not reach the MCP server at #{@server_url}: #{e.message}"
      ensure
        client.transport.close if client.transport.respond_to?(:connected?) && client.transport.connected?
      end
    end

    private

    def mcp_client
      @injected_client || MCP::Client.new(transport: MCP::Client::HTTP.new(url: @server_url))
    end

    def html(result)
      resource_item = Array(result["content"]).find { |item| item["type"] == "resource" }
      raise ToolError, "No UI resource returned for coffee place card" unless resource_item

      resource = resource_item["resource"]
      resource["blob"] ? Base64.decode64(resource["blob"]) : resource["text"]
    end

    def error_text(result)
      text_item = Array(result["content"]).find { |item| item["type"] == "text" }
      text_item ? text_item["text"] : "Unknown MCP tool error"
    end
  end
end
```

## MCP server (coffee place cards)

This app includes a standalone MCP server (`mcp_server/`) that exposes
coffee-spots data as MCP tools, including one that returns an MCP-UI HTML

$ bin/rails server       # terminal 1 — the Rails app, http://localhost:3000
$ bin/mcp_server          # terminal 2 — the MCP server, http://localhost:3001

render the card served by the MCP server inside a sandboxed iframe. Stop
`bin/mcp_server` and reload the page to see the fallback (plain attributes)
path instead.
